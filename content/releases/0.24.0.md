- **Releases on hourwarden.com**: Windows installer, Linux packages (.deb, .rpm) and the Android app built and signed by GitHub Actions from a version tag, with release notes on the site and the update feed for installed apps.
- **Licences of third-party code** ship inside the app (third-party-notices.txt); every dependency allows commercial use.
- **Smaller and faster**: release builds with link-time optimisation and without debug symbols; the server binary went from 15 to 6 MB.
- **Top bar** without the grey corners around its rounded edges.
- **Plugins**: a step-by-step guide to writing your own, and the plugin repository is now MIT licensed.
