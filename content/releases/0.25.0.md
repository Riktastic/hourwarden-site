- **Plugins run inside the app**: all 13 plugins are now WebAssembly modules run by HourWarden itself, sandboxed, instead of PowerShell scripts in a hidden process. Nothing runs scripts with the execution policy bypassed any more, which is what antivirus software objected to. Installed plugins are updated on the first start.
- **Each plugin only gets what its manifest lists**: what it reads from the system (Outlook, Teams, the browser's address bar, Office documents, the network, customer folders) goes through a small set of read-only capabilities of the app, and a plugin cannot read files, start programs or reach the network itself.
- **Plugins on Linux without PowerShell**: the plugins that work on Linux no longer need PowerShell 7 installed.
- Remote Desktop Manager no longer reads entries through the Devolutions PowerShell module; folders come from the tab names and the server from the remote desktop connection.
- A plugin that hangs is stopped after a time limit and restarted, like one that crashes.
