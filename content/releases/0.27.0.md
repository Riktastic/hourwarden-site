- **One version for everything**: the Windows and Linux app, the Android app and the server now always carry the same version number, released together.
- **New version notice on Linux and Android**: the app says when a new version is out, with a button to its download page. These apps do not update themselves.
- **Portable Windows version**: a zip without an installer; unzip it and run HourWarden.exe. It shows the same new-version notice.
- **PowerShell plugins removed**: HourWarden only runs the WebAssembly plugins now. A PowerShell plugin that is still installed does not start; its status asks you to install its new version from the store. The plugin store has no PowerShell plugins any more.
